Problem

Given an array of numbers and a window size k, return the maximum value in every contiguous window of size k.

Example:

Input:
nums = [1,3,-1,-3,5,3,6,7]
k = 3

Output:
[3,3,5,5,6,7]
Why this is FAANG-level

A brute-force solution checks every window:

O(n × k)
