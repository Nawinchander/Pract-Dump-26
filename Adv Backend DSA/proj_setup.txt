Recommended implementation order

Don't try to build everything simultaneously.

Follow this exact sequence:

Phase 1 — Project setup
1. npm init
2. Install dependencies
3. Create folders
4. Create .env
5. Configure Express

Phase 2 — Databases
6. Install/start MySQL
7. Create database
8. Create tables
9. Connect mysql2
10. Install/start MongoDB
11. Connect Mongoose

Phase 3 — Dijkstra
12. Implement PriorityQueue
13. Test PriorityQueue
14. Implement Graph
15. Implement Dijkstra
16. Test Dijkstra

Phase 4 — Route API
17. Repository
18. Service
19. Controller
20. Route
21. Test API
22. Save search to MySQL
23. Save traffic information to MongoDB
