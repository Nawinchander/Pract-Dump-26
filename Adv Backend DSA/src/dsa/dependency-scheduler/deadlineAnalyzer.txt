Objective
Imagine you have 5 tasks, each with a duration and a deadline. You have limited time, so you want to complete the maximum possible number of tasks before their deadlines.

We'll use a greedy algorithm with a Max Heap.

The strategy is:
1. Sort tasks by their deadlines.
2. Add each task's duration to the total scheduled time.
3. If the total exceeds the current task's deadline, remove the selected task with the longest duration.
4. Continue until all tasks have been considered.
This is useful for deadline-driven task planning, project management, and scheduling independent jobs.
