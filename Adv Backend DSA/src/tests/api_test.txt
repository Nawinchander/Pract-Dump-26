API 3 — K Shortest Routes

This extends your Dijkstra problem.

Instead of:

"Give me the shortest route from A to D."

the API answers:

"Give me the top 3 possible routes from A to D."

For example:

A → B → D       = 8
A → C → D       = 10
A → B → C → D   = 12

This is useful for a logistics/ride-booking/navigation system because the client can display multiple alternatives.

Endpoint


POST /api/routes/alternatives


{
  "source": "A",
  "destination": "D",
  "k": 3,
  "edges": [
    {
      "source": "A",
      "destination": "B",
      "weight": 4
    },
    {
      "source": "A",
      "destination": "C",
      "weight": 2
    },
    {
      "source": "C",
      "destination": "B",
      "weight": 3
    },
    {
      "source": "B",
      "destination": "D",
      "weight": 4
    },
    {
      "source": "C",
      "destination": "D",
      "weight": 8
    }
  ]
}


Response
{
  "success": true,
  "data": {
    "source": "A",
    "destination": "D",
    "routes": [
      {
        "path": ["A", "B", "D"],
        "distance": 8
      },
      {
        "path": ["A", "C", "B", "D"],
        "distance": 9
      },
      {
        "path": ["A", "C", "D"],
        "distance": 10
      }
    ]
  }
}
