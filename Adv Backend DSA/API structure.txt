API 5 — Route Network Analysis

This API answers:

"What is the shortest distance between every pair of locations in the network?"

This is different from Dijkstra.

Dijkstra:

A → D

Floyd-Warshall:

A → B
A → C
A → D

B → A
B → C
B → D

C → A
C → B
C → D
...

So it is useful when your logistics system needs a complete shortest-distance matrix.
