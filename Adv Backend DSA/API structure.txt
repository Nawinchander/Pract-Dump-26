Yes. Both problems are intended to be part of the same overall backend project, not two completely separate projects.

The structure I gave combines:

Smart Route Optimizer → Dijkstra + Priority Queue
Dependency Scheduler → Topological Sort + Critical Path

into one Node.js + Express application.
